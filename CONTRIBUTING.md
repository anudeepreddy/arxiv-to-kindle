# Contributing to arxiv-to-kindle

Contributions are welcome! Please feel free to submit a Pull Request.

## Development Setup

```bash
git clone https://github.com/yourusername/arxiv-to-kindle.git
cd arxiv-to-kindle
npm install
npm run build
```

## Running Tests

```bash
npm test
```

## Building

```bash
npm run build
```

## Publishing

```bash
# Publish both packages
npm run publish

# Or publish individually
npm run publish:core
npm run publish:cli
```
